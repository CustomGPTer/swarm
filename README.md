# Swarm

Swarm is a free torrent app for Android with search built in: see seeders, size and age, tap Download, and play videos while they download. A DHT index, your own search sources, no adverts and no paid version. Open source.

Website: https://customgpter.github.io/swarm/

Download: https://github.com/CustomGPTer/swarm/releases/latest/download/Swarm.apk

Source: the code for this version is on the `source` branch, under GPL-3.0. No signing key is included.
